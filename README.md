¡Bienvenido al repositorio de mi portafolio web! Este proyecto contiene el código fuente de mi página personal, diseñada para mostrar mis habilidades, experiencia y proyectos destacados.

## 🚀 Descripción

Este es un sitio web estático desarrollado con tecnologías web fundamentales. El objetivo principal es ofrecer una presentación profesional y accesible de mi trabajo. El diseño está enfocado en la claridad y la experiencia de usuario.

## 🛠️ Tecnologías Utilizadas

El proyecto está construido íntegramente con:

* **HTML5** (38.2%): Para la estructura semántica y el contenido.
* **CSS3** (44.5%): Para el diseño visual, estilos y adaptabilidad (Responsive Design).
* **JavaScript** (17.3%): Para añadir interactividad y dinamismo a la página.
